# WebMorph Security (Multi-Module)

Collection of three security modules for the **WebMorph** ecosystem—or any Spring-based system requiring flexible LuckPerms-based authorization.

---

## ⚙️ Requirements

* Java 17 or above

## 🔍 Overview

- [**security**](core) — Core Security Package  
  Base LuckPerms + Spring Security mechanisms for traditional MVC applications on Spring Boot.
- [**security-rsocket**](rsocket) — RSocket JWT Security  
  JWT authorization for RSocket services + Spring ReactiveMethodSecurity.
- [**security-webflux**](webflux) — WebFlux JWT Security  
  JWT authorization for reactive WebFlux applications + Spring ReactiveMethodSecurity.
